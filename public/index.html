📖 Complete User Guide (Step-by-Step) & How It Works

👶 Simple Explanation (ELI10 – Anyone Can Understand!):

Imagine you need a physical USB flash drive, but you don't have one plugged in. This program takes a regular file or folder on your PC and convinces Windows that you just plugged a real hardware thumb drive (like a Kingston or SanDisk) into a physical USB port! Windows plays the hardware connect sound, opens a new drive letter (e.g., D:), and lets you use it like a real USB stick.

🚀 Step-by-Step Guide (What to Click?):
  1. STEP 1 (Quick Start): Click the green "⚡ Quick Mount" button in the top-right corner.
  2. STEP 2 (Choose Source & Size): Select a Virtual Port (#1 to #4), pick an image file or local folder (V-FAT), and type any custom size in MB.
  3. STEP 3 (Plug It In): Click "🔌 INITIALIZE USB HOT-PLUG". Within 2 seconds, your new USB drive appears in Windows File Explorer!
  4. STEP 4 (Create Custom Drives): Open "🛠️ Disk Forge & Size" to type any custom size in MB and forge a pre-formatted FAT16/NTFS drive.

📖 Instrukcja Obsługi „Po Ludzku” (Krok po Kroku) & Zasada Działania

👶 Wyjaśnienie w 3 zdaniach (Zrozumie nawet 10-latka!):

Wyobraź sobie, że potrzebujesz pendrive'a, ale nie masz go w kieszeni. Ten program bierze zwykły plik lub folder z Twojego komputera i „udaje” przed Windowsem, że właśnie włożyłeś prawdziwego pendrive'a ze sklepu (np. firmy Kingston lub SanDisk) do gniazda USB! Komputer wydaje dźwięk podłączenia, pokazuje nowy dysk (np. D:), a Ty możesz wrzucać na niego pliki, gry i programy.

🚀 Instrukcja Krok po Kroku (Co kliknąć, żeby działało?):
  1. KROK 1 (Szybki Start): Kliknij zielony przycisk „⚡ Szybkie Montowanie” w prawym górnym rogu ekranu.
  2. KROK 2 (Wybór tego, co montujemy): Wybierz Port (od #1 do #4), wybierz gotowy plik dysku z listy (lub wskaż własny folder z komputera) i wpisz dowolny rozmiar w MB.
  3. KROK 3 (Podłączenie): Kliknij „🔌 ZAINICJUJ HOT-PLUG USB”. Po 2 sekundach w Eksploratorze Windows pojawi się Twój nowy pendrive!
  4. KROK 4 (Tworzenie nowych dysków): W zakładce „🛠️ Kuźnia & Rozmiar” możesz wpisać z palca dowolny rozmiar (np. 500 MB) i wykuć zupełnie nowy, sformatowany dysk.
